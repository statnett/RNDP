# Talk2PowerSystem

**Simpler CIM, also known as Talk2PowerSystem**

This project is a collaboration between GraphWise (previously Ontotext) and Statnett. Its purpose is to test the feasibility of using GraphWise's large language model (LLM) to answer questions about Statnett's Common Information Model (CIM) in natural language, rather than querying GraphDB directly. The first phase includes installing GraphWise's model and testing it on the Nordic 44 model.

More information about the project is available in [statnett/Talk2PowerSystem: Talk to the Power System](https://github.com/statnett/Talk2PowerSystem).

More information about GraphWise is available on the [GraphWise website](https://graphwise.ai/).

## Data Sources

The source material lists the following data sources, but the details need confirmation:

- CIM model 
- Nordic 44 / GraphDB
- Cognite API
