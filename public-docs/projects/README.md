# Projects on RNDP

Four projects have been hosted on the RNDP platform so far. This index will link to their individual pages as the documentation is added.

- [Talk2PowerSystem](talk2powersystem.md) — explores natural-language queries against Statnett's CIM model using a large language model.
- [S.W.A.M.P (p-SWAMP)](p-swamp.md) — explores wide-area power-system monitoring and applications based on PMU measurements.
